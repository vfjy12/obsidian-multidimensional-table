## 主要功能

- 独立的“考公词典”工作台：收件箱、正式词条、待补充、概念组、时间线、地点、重复检查和全部词条。
- 收件箱维持原整理交互；正式词条、待补充、概念组、重复检查和全部词条统一使用原多维表格视图，Markdown 仍是已归档词条的主数据。
- 智能范围可手动新增并拖动排序；非收件箱范围右侧菜单支持模板、原始数据、批量导入和批量生成 Markdown。自动范围会保留尚未生成笔记的手工行，避免刷新时丢失待处理数据。
- 多维表格左侧考公词典导航默认折叠；展开按钮只控制第一栏。关闭右侧词条编辑器后整列收回，右侧固定把手可随时重新展开，选择其他词条不会擅自弹回编辑栏。
- 词条类型仍使用 YAML 的 `entry_type` 普通字段（概念、定义、实体、术语、成语、方法等），不作为左侧可新建的范围。
- “词条范围”模块不再显示；当前只管理“智能范围”，避免两个范围系统重复。
- 智能范围的右侧更多按钮和鼠标右键提供相同管理菜单；自建智能范围移除时需要二次确认，并且不会删除原 `.duowei`、Markdown、模板或已生成文件。
- 点击智能范围名称直接打开原多维表格完整界面，不再保留重复的“打开原始表格”菜单；单元格仍可点击/双击进入原编辑流程。
- 在编辑器中选中文字后，通过右键菜单或命令“把选中文字收进考公词典”采集词条。
- 自动保存选中文字、上下文和来源笔记双链。
- 编辑词条名称、类型、定义、我的理解、适用场景、方法步骤、易错点、老师、关键词、人工星级、概念组、父节点和相关词条。
- 自动按实际反向链接显示“低 / 中 / 高＋引用次数”，人工重要性另用 1–5 星表示；没有点星的词条不进入人工星级统计。
- 收件箱词条可以“整理入典”，文件从 `00-收件箱` 移到 `10-正式词条`。
- 同名词条和相似词条只提示，不自动合并。
- 新词条默认加入 Spaced Repetition；有定义时以定义作背面，没有定义但有收集摘录时以摘录作背面，两者都没有时不生成空卡。重新保存时保留已有 `<!--SR:...-->` 调度标记。
- Windows 收件箱使用三栏整理，正式词条使用两栏表格；iPad 与手机在窄屏下按列表、详情、网页单屏切换。
- 为漫游插件提供 `captureToLexicon(payload)`、带保存回调和 `openAfterSave` 控制的 `openLexiconCapture(payload)`，以及 `mountLexiconEditor(container, entry, options)` 内嵌编辑接口。
- 从漫游创建词条后自动回调建立题目正文双链与 YAML 关系；回链失败会明确提示，不会把已保存词条误报成保存失败。
- 新生成的词条正文不写物理空行，需要视觉间距时统一写 `<br>`。
- 时间词条保存原始表达、起止时间、精度和相关表达。可用“公元221年”“晚唐”“康熙二十年”等口径搜索；年号换算用于候选检索，不等同于完成史料核验。
- 地点词条同时保存现代位置、历史名称、地点精度和范围说明。“上党”“潞州”“长治”等只按具体时代与行政范围建立关联，不自动视为完全同一地点。
- “时间线”按可解析的起始年份排序；“地点”可用历史名称模糊检索。同名地名会同时返回候选，例如“东京”可能命中洛阳和开封，再依据朝代消歧。
- 收件箱词条和词典多维表格的“词条”列提供网络搜索按钮，其他元数据列不显示。查证时第二栏由表格切换为网页，第三栏继续保留词条编辑；关闭网页栏后第二栏恢复表格。受网站安全策略限制无法内嵌时，可改用外部浏览器。查询不会自动修改词条或把网页摘要当成已核验事实。
- 命令“导入基础时间与地点词条”提供一组少量示例。导入按 `entry_id` 和标题去重，保留已有内容，只补充空字段及缺少的别名。

## 时间、地点与证据字段

```yaml
time_expression: "康熙二十年（公元1681年）"
time_start: "1681"
time_end: "1681"
time_precision: "年"
time_aliases: ["康熙20年", "1681年"]
place_current: "山西省长治市"
historical_names: ["上党", "潞州"]
place_precision: "约"
place_note: "行政范围和治所随时代变化"
verification_status: "待核验"
evidence_note: "记录采用口径、反例与未知项"
source_urls: []
importance_stars: ""
review_enabled: true
```

`verification_status` 只表示当前词条的核验进度。没有可靠来源网址的内置示例不会伪装成“已核验”。

## 文件结构

首次保存词条时自动建立：

```text
考公词典/
├─ 00-收件箱/
├─ 10-正式词条/
├─ 20-概念组/
├─ 30-老师与来源/
├─ 40-智能范围/
└─ 90-模板/
```

词条的结构字段放在 YAML，定义和学习内容放在 Markdown 正文，来源使用普通 Obsidian 双链。

## 漫游插件调用

其他插件可以通过当前插件实例调用：

```js
await plugin.captureToLexicon({
  text: "选中的原文",
  context: "原文上下文",
  sourcePath: "题库/某道题.md",
  sourceSection: "题干",
  title: "可选的词条名"
});
```

该接口默认写入收件箱并启用 Spaced Repetition；只有定义和摘录都为空时才暂不生成复习卡。它不会自动合并相似词条。
